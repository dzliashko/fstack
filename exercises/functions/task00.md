5. Практическое упражнение

какие случаи немедленно делают платёж недопустимым

- invoiceTotal < 0 — некорректная сумма счёта;
- paidAmount < 0 — некорректная уже оплаченная сумма;
- newPaymentAmount <= 0 — нулевой или отрицательный платёж (записывать нечего);
- invoiceCancelled — счёт отменён, платежи по нему больше не принимаются.

какое последнее условие определяет, был ли счёт уже полностью оплачен

- paidAmount < invoiceTotal: оно проверяет, остался ли по счёту непогашенный остаток
